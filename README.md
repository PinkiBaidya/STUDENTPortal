# STUDENTPortal

STUDENTPortal is a simple and user-friendly web application built with **ASP.NET** in **Visual Studio 2022**.  
It allows users to manage student information using **SQLite local database storage**, making it easy to run without complex database setup.

---

## 🚀 Features

- 👤 **Student Registration & Login**
- 📋 **View Student List**
- ➕ **Add New Students**
- ✏️ **Edit Student Details**
- ❌ **Delete Students**
- 🔐 Basic login-based authentication
- 🗂️ SQLite local database (.db file)

---

## 🛠️ Tech Stack

- **Framework:** ASP.NET  
- **Language:** C#  
- **Database:** **SQLite (Local Storage)**  
- **ORM:** Entity Framework Core (if applicable)  
- **IDE:** Visual Studio 2022  
- **Version Control:** Git & GitHub
